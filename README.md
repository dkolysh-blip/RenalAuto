# RenalAuto

Собственный сервис для мониторинга объявлений о продаже б/у авто в **Южной Корее** и **Китае**
в реальном времени, с **проверкой по VIN**.

- **Площадки:** Encar (Корея) и Dongchedi / 懂车帝 (Китай). Новые площадки подключаются одним классом-адаптером.
- **Реальное время:** фоновый опрос каждые `POLL_INTERVAL` секунд → новые объявления и изменения цены
  сразу попадают в поток (SSE), в веб-интерфейс и в Telegram по сохранённым фильтрам.
- **Проверка VIN:**
  - формат и контрольный знак (ISO 3779; в Китае по GB 16735 он обязателен, поэтому ошибка там = подделка или опечатка);
  - производитель по WMI (корейские и китайские заводы), страна, модельный год;
  - сверка с объявлением: марка по VIN ↔ марка в объявлении, модельный год ↔ год в объявлении;
  - **скрутка пробега**: сервис хранит историю каждого объявления, и если тот же VIN позже всплывает с меньшим пробегом — это флаг;
  - **перевыставление**: один VIN в нескольких объявлениях/на разных площадках;
  - для Encar — **страховая история** (ДТП и суммы выплат, смены владельцев, тотал, утопленник, угон, такси/прокат);
  - опционально — бесплатный декодер NHTSA vPIC.

## Запуск

```bash
cp .env.example .env        # при необходимости укажите прокси и Telegram
docker compose up -d --build
# или без Docker:
pip install -e ".[dev]"
python -m renalauto
```

Откройте http://localhost:8000 — живая лента объявлений и форма проверки VIN.
Документация API (Swagger): http://localhost:8000/docs

> **Сеть.** Корейские и особенно китайские площадки режут запросы с «чужих» IP и дата-центров.
> Для стабильной работы укажите `PROXY_KR` / `PROXY_CN` (резидентные прокси в стране площадки).
> Состояние каждой площадки (последний успех / ошибка) видно в `GET /health`. При ошибках опрос
> автоматически замедляется (экспоненциальная пауза до 15 минут).

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/listings?country=KR&make=현대&year_from=2020&price_usd_max=15000` | Поиск по накопленной базе |
| GET | `/api/listings/{source}/{id}?refresh=true` | Объявление + история цены/пробега (`refresh` — перечитать карточку) |
| GET | `/api/listings/{source}/{id}/vin-report` | Полная проверка VIN из объявления |
| GET | `/api/vin/{vin}` | Полная проверка произвольного VIN |
| GET | `/api/vin/{vin}/decode?year=2021` | Только офлайн-расшифровка VIN |
| GET | `/api/stream?country=CN&make=比亚迪` | Поток новых объявлений (Server-Sent Events) |
| GET/POST/DELETE | `/api/filters` | Сохранённые поиски (уведомления в Telegram) |
| POST | `/api/poll/{source}` | Внеочередной опрос площадки |
| GET | `/health` | Состояние сервиса и площадок |

Пример сохранённого фильтра:

```bash
curl -X POST localhost:8000/api/filters -H 'Content-Type: application/json' \
  -d '{"name":"Palisade до $30k","country":"KR","make":"현대","model":"팰리세이드","year_from":2021,"price_usd_max":30000}'
```

Подписка на поток из кода:

```js
const es = new EventSource('/api/stream?country=KR&make=기아');
es.addEventListener('new', e => console.log(JSON.parse(e.data).listing));
es.addEventListener('price_changed', e => console.log(JSON.parse(e.data)));
```

## Как это устроено

```
renalauto/
  sources/        адаптеры площадок (encar.py, dongchedi.py) → единая модель Listing
  poller.py       фоновый опрос, прогрев базы без спама, догрузка карточек (VIN), backoff
  storage.py      SQLite: объявления, история наблюдений (цена/пробег/VIN), фильтры
  events.py       шина событий для SSE
  notify.py       Telegram
  vin/decoder.py  офлайн-расшифровка VIN (контрольный знак, WMI, модельный год)
  vin/report.py   сводная проверка VIN
  api.py          FastAPI + веб-интерфейс (static/index.html)
```

Первый опрос каждой площадки только наполняет базу — уведомления начинают приходить со второго,
чтобы не получить сотню «новых» старых объявлений при старте.

### Особенности площадок

- **Encar** — VIN и госномер есть в карточке, поэтому для новых объявлений карточка догружается
  автоматически (`ENRICH_DETAILS`). Цена в API в 만원 (×10 000 вон). Страховая история берётся из того же
  отчёта, что Encar показывает покупателям (данные KIDI / carhistory.or.kr).
- **Dongchedi** — VIN целиком обычно не публикуется. Запросите его у продавца и проверьте через
  `/api/vin/{vin}`: сервис сверит его с известными объявлениями и историей пробега. Цены в 万元 (×10 000 юаней).

### Добавить площадку

Унаследуйте `renalauto.sources.base.Source`, реализуйте `fetch_latest` (и, если есть, `fetch_detail` /
`fetch_history`) и добавьте класс в `REGISTRY` в `renalauto/sources/__init__.py`. Кандидаты:
KB Chachacha, K Car (Корея); Che168 / 二手车之家, Guazi / 瓜子 (Китай).

### Платные отчёты

Полные официальные отчёты (carhistory.or.kr в Корее; 查博士 / 车鉴定 — ремонты у дилеров и страховые
в Китае) требуют договора и ключа. Их удобно подключить как ещё один шаг в `vin/report.py`.

## Важно

Эндпоинты площадок — неофициальные (это те же JSON-запросы, что делает их сайт), они могут меняться;
разбор ответов сделан устойчивым к отсутствующим полям, а схемы зафиксированы в `tests/fixtures`.
Соблюдайте правила использования площадок и не ставьте слишком частый опрос.
