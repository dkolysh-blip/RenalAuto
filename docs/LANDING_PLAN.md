# Лендинг «Порт» — план до запуска

Страница `/port`: на неё ведём трафик из Яндекс Директа.
Структура: **порт с путём машины → калькулятор → отзывы → сделка и оплата → вопросы → заявка**.
Порт здесь только визуальный образ: о «нашем терминале» не пишем.
Фирменный стиль — брендбук Renal Auto (логотип, цвета, шрифты, бирки, шаги маршрута).

## Неделя 1 — запуск в Директ

- [x] Путь машины встроен под сцену порта, длинный блок логистики и лента «Свежие объявления» убраны
- [x] Калькулятор: марка → модель → год из объявлений; на телефоне ручные параметры свёрнуты
- [x] Названия машин без корейских и китайских слов
- [x] Логотип в векторе, знак в шапке и подвале
- [x] Телефон +7 (914) 066-88-08
- [ ] На сервере: строка `COMPANY_PHONE` в `.env`
- [ ] Отзывы: 3–5 текстов со скриншотов 2ГИС, оценка и число отзывов
- [ ] Фото выдач в блок отзывов
- [ ] Проверка на телефоне с настоящими объявлениями
- [ ] Небольшой бюджет на 2–3 модели со ссылками `?model=`
