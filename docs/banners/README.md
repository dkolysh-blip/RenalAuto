# Баннеры для Яндекс Директа

Фото сгенерированы в Higgsfield (модель SOUL Cinema) — это иллюстрации порта, судна и автовоза, а не фото наших выдач.
Выдуманная эмблема на борту судна закрашена. Логотипов чужих компаний и надписей на фото нет.

- `banner-*-1080x607.jpg` — 16:9, `banner-*-1080x1080.jpg` — 1:1; `both` — Корея и Китай, `kr` — Корея (судно), `cn` — Китай (автовоз).
- `photos/` — те же фото без текста: для текстово-графических объявлений, где текст добавляет сам Директ.
- `banner.html` — макет: открыть в браузере с параметрами `?f=w|s&img=<фото>&v=both|kr|cn` и сделать снимок блока `.b`.

Адрес на баннерах — renal-auto.ru: запускать после переезда (docs/MOVE_SERVER.md).
