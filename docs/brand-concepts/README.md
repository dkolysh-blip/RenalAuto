# Знак без ворот — варианты

Сгенерированы в Higgsfield (Recraft V4.1) по описанию «силуэт машины, чёрный и фирменный красный, без текста»,
затем переведены в вектор. Надпись «РЕНАЛ АВТО · Корея · Китай» — наша, шрифтом Unbounded.

- `mark-e.svg` — машина одним мазком над красной линией дороги
- `mark-f.svg` — линия кузова и колёсных арок, красная линия крыши
- `mark-g.svg` — контур одной линией, красная точка-фара
- `lockups.jpg` — все варианты с надписью в строку и в столбик

Перед регистрацией товарного знака стоит проверить, что знак не похож на зарегистрированные (поиск ФИПС).
